# Quick Command Vault

A lightweight webapp for quickly finding commands and copying them to the clipboard.

## Features

- Fast search by natural task names, e.g. `application upgrading`
- Category filters
- One-click copy
- Windows / CMD / Code Runners / Git / Kali Linux
- Keyboard shortcut: `Ctrl + K`
- `Esc` clears the search
- No framework, build step, backend, database, or dependencies
- Responsive dark interface
